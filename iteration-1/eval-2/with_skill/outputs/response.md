按照技能约束，**我不会降级到本地启发式、不会编造概率**——那不是 jev-life 在工作，那是普通聊天建议。请检查：

- 是否在 `.env` / `.claude/.env` 里声明并被加载
- key 是否还有余额、是否过期

## 关于这个问题本身

顺便说明一下，正常流程下，jev-life 不会直接给你"该怎么办"的答案。它会先走 Step 1，向你追问两个字段：

- **背景**：合租环境、你和室友的关系、其他共处细节、碗堆久了会怎样（发霉？影响你做菜？只是看着烦？）
- **实际情况**：他是怎么回应的——是真没意识到、觉得无所谓、还是明确拒绝改？频率如何？

拿到这两块之后才构造 Choice（候选策略）+ Noul（成功率）+ Score（生活质量）三件套，跑 Jev，把概率分布原样还给你，由你自己决定。

你目前只给了"实际情况"的一小段，背景几乎是空的。即便 API 配好了，下一步我也会先回头追问这些，再进入 Step 2。
